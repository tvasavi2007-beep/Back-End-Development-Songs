# Back-End Development – Songs Microservice

## Project Description

This project is a Flask-based RESTful API microservice for managing song records.

It supports creating, retrieving, updating, deleting, and counting song records using HTTP methods and JSON responses.

## Technologies Used

- Python
- Flask
- REST API
- JSON
- Pytest
- Git and GitHub

## API Endpoints

- GET /health
- GET /song
- POST /song
- PUT /song/<id>
- DELETE /song/<id>
